# Personal Portfolio Website

This is my personal portfolio website built with HTML and CSS, hosted on GitHub Pages. The site showcases my professional experience, projects, and skills.

## Features

- Responsive design that works on all devices
- Modern and clean UI
- Sections for About, Experience, Projects, Skills, and Contact
- Social media integration
- Smooth scrolling navigation
- Project showcase with links to GitHub repositories

## Setup Instructions

1. Fork this repository to your GitHub account
2. Rename the repository to `yourusername.github.io` (replace 'yourusername' with your GitHub username)
3. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/yourusername.github.io.git
   ```
4. Customize the content in `index.html`:
   - Update personal information
   - Add your experience
   - Link to your projects
   - Update skills
   - Add your contact information
5. Customize the styling in `styles.css` if desired
6. Commit and push your changes:
   ```bash
   git add .
   git commit -m "Customize portfolio content"
   git push origin main
   ```
7. Your site will be available at `https://yourusername.github.io`

## Customization Guide

### Personal Information
- Update the name and title in the hero section
- Add your social media links
- Update the about section with your bio

### Experience
- Add your work experience in the experience section
- Include company names, positions, and dates
- List key achievements and responsibilities

### Projects
- Add your GitHub projects
- Include project descriptions
- Link to live demos if available

### Skills
- List your technical skills
- Group skills by category
- Add proficiency levels if desired

### Contact
- Add your email address
- Include any other contact methods
- Add a contact form if desired

## Customizing the Design

The site uses a clean, modern design with a responsive layout. You can customize the colors, fonts, and layout by modifying the CSS in `styles.css`:

- Change the color scheme by updating the color values
- Modify the layout by adjusting the grid and flex properties
- Update the typography by changing the font families and sizes
- Add animations and transitions for interactive elements
